A노드의 종류NODE TYPES · .fig-node
노드는 .fig-node 하나의 규칙만 따르는 빈 박스입니다. 배경과 테두리와 모양을 자유롭게 정해 아래 여덟 가지처럼 다른 역할을 줄 수 있습니다.
TYPE 01
카드형
흰 배경과 테두리, 둥근 모서리, 옅은 그림자를 가진 기본 박스입니다. 대부분의 도식은 이 카드에서 출발합니다.
background · border · radius
TYPE 02 · 원형
원형
중심 허브나 강조 요소에 적합합니다. border-radius:50% 하나로 완전한 원이 됩니다.
TYPE 03 · 투명
투명 노드
배경과 테두리를 모두 없앤 노드입니다. background:transparent 뒤 캔버스가 그대로 비칩니다. 캡션과 라벨, 지금 읽는 이 섹션 제목도 모두 이 방식입니다.
TYPE 04 · 반투명
배경에 알파값을 주면 아래 요소가 비쳐 보입니다. rgba() · opacity
TYPE 05
그림자 강조형
큰 box-shadow로 떠 있는 느낌을 줍니다. 뒤에 깔린 평면 카드와 비교해 보세요.
TYPE 06
그라디언트
선형과 방사형 그라디언트로 색감과 방향성을 더합니다. 허브나 시작점 노드에 자주 씁니다.
linear-gradient()
TYPE 07
점선 테두리
예정이거나 미확정인 상태, 또는 그룹의 경계를 나타낼 때 씁니다.
border-style:dashed
TYPE 08
아이콘 배지형
icon + text row
아이콘 사각형과 텍스트를 가로로 묶어 기관이나 항목을 나타냅니다.
svg + flex
